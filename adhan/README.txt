ADHAN FILES
===========
These two recordings are the only sounds the site uses:

  Adan1.mp3   plays at Fajr
  Adan2.mp3   plays at Dhuhr, Asr, Maghrib and Isha

To change one later: upload a new file with the SAME name (capital A, .mp3) to this
folder on GitHub (Add file > Upload files > Commit changes). Phones pick up the new
one quietly.

Notes
- Each phone saves both files the first time the adhan is switched on, so they also
  play with no internet. Large files take longer to download, so keeping each under
  about 3 MB (128 kbps) is kinder to people's data.
- Only use recordings you have the right to publish on your website.
- Visitors cannot upload or change the adhan; only the files in this folder are used.
