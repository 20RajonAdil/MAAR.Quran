ADHAN FILES
===========
Put your own recordings in this folder, named EXACTLY like this (capital A, .mp3):

  Adan1.mp3   plays at Fajr
  Adan2.mp3   plays at Dhuhr, Asr, Maghrib and Isha

Until a file is added, the bundled recording (adhan.mp3) plays instead,
so nothing breaks while you are getting your files ready.

How to add them on GitHub: open the "adhan" folder > Add file > Upload files >
drop Adan1.mp3 and Adan2.mp3 > Commit changes. They are cached on each phone the
first time the adhan is switched on, so they also play with no internet.

Tips
- MP3, mono or stereo, under about 3 MB each keeps phones quick (64-128 kbps is plenty).
- Only use recordings you have the right to publish on your website.
- If you replace a file later, keep the same name. Phones pick up the new one quietly.
