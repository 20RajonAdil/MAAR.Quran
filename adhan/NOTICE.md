# Adhan audio

`adhan.mp3` is "Muslim calling to prayer" by Aishatu98 (Wikimedia Commons).

- Source:  https://commons.wikimedia.org/wiki/File:Muslim_calling_to_prayer.ogg
- Licence: CC0 1.0 Universal (public-domain dedication), so attribution is not required; it is given as a courtesy.
- Modifications: converted to mono MP3 (64 kbps) for the web. The loudness-normalised master was taken from the open-source Barakah project (github.com/TheOddjobShop/barakah), whose NOTICE records that it checked the licence against the Wikimedia Commons API.

Please confirm the licence on the Commons file page yourself before relying on it.

`adhan.mp3` is only the fallback. The site plays `Adan1.mp3` at Fajr and `Adan2.mp3` at the other prayers when those files are present (see README.txt).

You can use a different adhan: people can pick their own audio file in Settings > Adhan (it stays on their device), or you can replace `adhan.mp3` with a recording you have the rights to use.
